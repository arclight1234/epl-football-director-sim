# EPL 축구 단장 시뮬레이터

2026-27 시즌 개막 시점을 배경으로 하는 AI 채팅형 EPL 단장 시뮬레이터 설계 프로젝트입니다.

## 현재 범위

- 선택 가능한 구단: 2026-27 EPL 참가 20개 구단
- 선수 풀: 전 세계 실제 선수(데이터 출처와 구축 방식은 추후 확정)
- 사용자 역할: 감독이 아닌 단장/스포팅 디렉터 중심
- 능력치: FM 이용자에게 익숙한 1-20 척도의 축약 모델
- 진행 방식: 이적, 재정, 선수단 구성, 감독과의 협업, 시즌 운영을 대화형으로 처리

## 문서 안내

- `docs/DESIGN.md`: 현재까지 합의한 시스템 설계
- `docs/DECISIONS.md`: 확정 사항과 이유
- `docs/ROADMAP.md`: 앞으로 논의하고 제작할 순서
- `docs/CHAT_TRANSCRIPT.md`: 현재 작업 대화의 사용자/어시스턴트 공개 메시지 기록
- `docs/ORIGINAL_CONVERSATION.md`: 출발점이 된 ChatGPT 대화 요약 기록
- `references/`: 사용자가 제공한 KBO/LoL 예시 프롬프트 원본
- `scripts/export-chat.ps1`: Codex 대화 기록에서 공개 메시지만 다시 추출하는 도구

## 운영 원칙

설계가 확정되기 전에는 거대한 최종 프롬프트를 만들지 않습니다. 각 시스템을 순서대로 합의하고, 결정 문서와 설계 문서를 먼저 갱신한 뒤 최종 프롬프트와 게임용 상태 파일을 제작합니다.

현재 Codex 작업 환경에서는 `.git` 폴더 쓰기가 제한되어 Git 메타데이터를 `work/git-meta`에 분리합니다. 이 컴퓨터에서 수동으로 Git 명령을 실행할 때는 `scripts/project-git.ps1 status`처럼 도우미를 사용할 수 있습니다. 원격 저장소를 다른 컴퓨터에 복제한 사본에는 이 제약이 없습니다.
